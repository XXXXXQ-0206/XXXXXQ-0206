# XQ Academic Homepage

This repository contains a GitHub Pages-ready academic personal homepage for **XQ**, a Computer Science student at Chongqing University.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages Deployment

For a user site, name the repository `XXXXXQ-0206.github.io`, push this project to the default branch, and enable GitHub Pages from the repository settings. The generated Vite site can be deployed with GitHub Pages or any static hosting provider.
